Container queries : comment adapter une carte à la place disponible ?

  • Résolu
  • Développement web

  • #responsive
  • #container-queries

5 réponses · 1 248 vues · dernière activité il y a 12 min

Aller à la solution

Merveille Tshibanda

aujourd'hui à 8 h 40

Bonjour à toutes et à tous ! J'ai une carte « article » (image à gauche, texte à droite) que j'utilise à deux endroits : dans le fil, et dans la colonne de droite, beaucoup plus étroite.

Pour passer l'image au-dessus du texte sur petit écran, j'ai écrit ceci :

.carte__contenu {
  display: grid;
  grid-template-columns: 8rem 1fr;
}

@media (width < 40rem) {
  .carte__contenu {
    grid-template-columns: 1fr;
  }
}

Le souci : sur un écran de 1 440 px, la colonne de droite ne fait que 14 rem de large. La media query ne se déclenche pas et l'image écrase le texte. Comment faire pour que .carte__contenu s'adapte à la place qu'on lui donne, et non à la taille de l'écran ?

    C'est exactement le cas d'usage des container queries ! Une media query regarde l'écran ; une container query regarde un élément parent. Ta carte réagira donc à la colonne dans laquelle elle est posée.

    Répondre

  2. Grâce Mwamba

    il y a 1 h 15

    Solution acceptée

    Déclare le parent de la carte comme conteneur, puis remplace ta media query par une règle @container : 

    .carte {
  container-type: inline-size;
}

.carte__contenu {
  display: grid;
  gap: 1rem;
}

@container (width >= 30rem) {
  .carte__contenu {
    grid-template-columns: 8rem 1fr;
  }
}

    La carte empile l'image et le texte tant qu'elle mesure moins de 30 rem, où qu'elle se trouve. Bonus : l'unité cqi (1 % de la largeur du conteneur) permet aussi d'adapter la taille du titre.

    Répondre

  3. Ben Uzan

    il y a 1 h

    Petit piège que j'ai rencontré : un élément ne peut pas interroger sa propre taille. Place bien container-type sur .carte, et non sur .carte__contenu que tu veux modifier.
